# School AI：帮助老师使用 AI

通过简单演示和与老师交流，发现真实需求，尝试用 AI 改善工作方法，并让愿意学习 AI 的孩子在成人指导下参与真实项目。

## 项目文档

- [教师需求清单](docs/教师需求清单.md)：一条一个需求，持续补充。
- [需求分析与探索方案](docs/教师AI赋能项目-需求分析与探索方案.md)：项目方向、演示思路和访谈方法。

## 共同协作

日常通过微信沟通，需求和交流成果使用腾讯文档共同维护；代码、工具和阶段性文档版本使用本 GitHub 私有仓库管理。

- 腾讯文档：[教师需求清单](https://docs.qq.com/doc/DV3FNeEJJRFhEV3ZW)。当前权限为“仅我自己”，尚未添加协作者；待确认指定人员后再授予查看或编辑权限，不开放任何人持链接访问。
- 腾讯文档与 GitHub 尚未建立自动同步，两处内容需手动维护。

开发和文档修改请在自己的分支提交，通过 Pull Request 合并到 main。需求清单保持简单，不必添加复杂字段。

真实学生信息、学校内部原始材料、账号凭据和本机安装记录不上传到仓库；演示优先使用虚构或脱敏材料。
