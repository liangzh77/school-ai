## 维护说明

- 两份文档创建时均已核实权限为“仅我自己”，尚未添加协作者。后续按确认的指定人员授予查看或编辑权限，不开放任何人持链接访问。此索引中的链接不授予访问权限，实际权限以腾讯文档为准。
- Git 记录此索引的版本，不自动备份腾讯文档正文或记录其编辑历史；腾讯文档与 GitHub 尚未建立自动同步。
- 仓库内的[教师需求清单](教师需求清单.md)是本地文字记录，在线表格变化后如需保留对应版本，应手动更新本地记录。
